# Prompt — Code Review

```text
Faça review deste PR segundo Handbook/18-CODE-REVIEW.md e capítulos relacionados.
Classifique cada achado como BLOQUEANTE, IMPORTANTE, SUGESTÃO ou DÚVIDA.
Priorize defeitos, segurança, arquitetura, concorrência, persistência, contrato, resiliência, testes e observabilidade.
Não gere comentários de estilo que formatter/analyzers já resolvem.
Para cada achado, informe arquivo/trecho, risco e correção objetiva.
Finalize com: decisão recomendada (aprovar / solicitar alterações) e checklist resumido.
```
